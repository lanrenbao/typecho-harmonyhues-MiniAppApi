## 二、服务端：安装 MiniAppApi 插件

1. 上传 `MiniAppApi-1.5.8.zip` 到服务器，解压得到 `MiniAppApi/`，放进 `usr/plugins/`。
2. 后台 → 控制台 → 插件 → **启用** MiniAppApi。
3. 验证：浏览器访问 `https://www.xiehongwei.cn/api/ping`，返回 `{"code":0,"data":{"version":"1.5.8",...}}` 即成功。

### ⚠️ 更新插件的铁律

- **只覆盖文件、没新增路由时**（改设置项、改逻辑）：直接覆盖 Action.php / Plugin.php 即可。
- **新增了路由时**（如历史上新增 `/api/hitokoto`）：必须后台 **禁用 → 再启用**，否则路由没写进数据库，接口 404。拿不准就每次更新都做一次禁用→启用。
- 启用插件会用表单默认值覆盖配置，1.5.1 起已做**配置回填**（token、开关等不会被清空），但更新后仍建议进设置页扫一眼。

## 三、独立一言接口 yiyan.php（可选）

单文件、不依赖插件和数据库，放站点根目录即用：`/wwwroot/yiyan.php`。

```
https://www.xiehongwei.cn/yiyan.php            JSON（hitokoto 兼容字段 + 本项目字段）
https://www.xiehongwei.cn/yiyan.php?format=text 纯文本
https://www.xiehongwei.cn/yiyan.php?img=0       不返回配图
```

数据源固定为 `usr/themes/HarmonyHues/assets/yiyan/`（yiyan.txt + 图库图片），CORS 全开，图片地址用当前请求域名拼接。

> 插件设置里「一言接口地址」填这个文件的网址也可以，插件会识别为本站并直接读本地文件，效果一样且更快。

## 四、小程序端配置与导入

### 1. 全局配置（只需改 `config.js`）

| 字段 | 当前值 | 说明 |
|---|---|---|
| `apiBase` | `https://www.xiehongwei.cn` | 站点地址，结尾不带 / |
| `token` | 与插件设置一致 | 插件留空则此处留空 |
| `useIndexPhp` | `false` | 站点未开伪静态改 `true` |
| `devBase` | 空 | 本地联调代理地址，**发布前必须为空** |
| `pageSize` | 12 | 每页文章数（接口上限 30） |
| `author` | `xiehongwei` | 海报上的作者名（接口无作者字段，手填） |
| `timeout` | 15000 | 请求超时（毫秒） |

### 2. 导入

1. 微信开发者工具 → 导入项目 → 选 `wx-miniprogram/` 目录，AppID 填**自己小程序**的（仓库里 `project.config.json` 是占位符 `xxxxxxxx`，也可在导入界面直接输入并勾选记住）。
2. 模拟器点**编译**即可看效果。

### 3. 云服务（登录 / 收藏 / 浏览记录）

「我的」页的邮箱验证码登录、收藏、阅读记录走 WorkBuddy 云服务，需要改 `wx-miniprogram/utils/cloud.js`：

```js
const cloud = createMiniProgramWorkBuddyCloud({
  endpoint: 'https://mp-api.app.workbuddy.host',   // 云服务面板给出的 endpoint，二选一填自己的
  publishableKey: 'wbpk_REPLACE_WITH_YOUR_OWN_KEY' // ← 换成你自己应用的值
});
```

两个值都在 WorkBuddy 云服务面板的 publicConfig 里。**本仓库里的都是占位符**，不换的话登录会失败（收藏、记录一起失效），但文章浏览不受影响。

关于这个 key 的定位：

- 它只**标识是哪个应用**，本身不带任何权限；服务端会校验请求来源（Origin / 应用绑定），换到别的域名或别的应用下调用会被拒绝。
- 它必然存在于小程序包里（客户端初始化需要用），所以**不能当作机密**，也无法通过"删除它"来彻底防止别人看到。
- 真正需要防的是验证码被刷：平台侧对同一邮箱有发送频次限制；如果仍然担心，可以在云服务面板关闭邮箱登录 Provider（登录入口随之失效），或在下线前观察面板的注册统计是否有异常增长。

### 3. ⚠️ 上线前必做：合法域名

mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名：

- **request 合法域名**：`https://www.xiehongwei.cn`
- **downloadFile 合法域名**：`https://www.xiehongwei.cn`

> 小程序里所有图片、头像、二维码都强制走 `www.`（裸域 `xiehongwei.cn` 会被服务端统一规范化成带 www），白名单只配 `www.` 即可。开发者工具里可勾选「不校验合法域名」先调试，真机预览必须配好。
> 云服务（登录/收藏）走 WorkBuddy 云端（`mp-api.app.workbuddy.host`），由 SDK 处理，如登录报网络错误，把该域名也加入 request 合法域名。

## 五、各功能区说明与部署细节

### 1. 首页（文章 + 轮播）

- 文章列表 `/api/posts`，下拉刷新 + 上拉加载。
- **轮播**：插件开关控制。内容自动引用网页端首页轮播（服务端抓自己站点 HTML 解析 HarmonyHues 结构，缓存 1 小时），也可在插件里用 `sliderJson` 覆盖。
- 点击轮播卡：`/archives/数字.html` 进小程序文章详情；slug 链接先转 id；外链复制到剪贴板。

### 2. 分类页

- `/api/categories` 分类列表；点进分类看文章（`category=mid`）。
- **封面大图**：插件开关控制，自动引用网页端分类页封面（缓存 1 天），可用 `categoryCover` 覆盖。
- 文章卡片缩略图取网页端给文章设置的自定义缩略图。

### 3. 文章详情（packagePost/detail）

- Markdown 渲染，`/api/post?id=或slug`。
- **底部四宫格：收藏 / 海报 / 赞赏 / 分享**
  - **收藏**：走云服务（登录后可用，`utils/userdata.js`）。
  - **海报**：离屏 canvas 生成 3:2 封面分享图，二维码指向**网页端** `https://www.xiehongwei.cn/archives/{cid}.html`；文件名 `xiehongwei-<slug或post+id>-YYYYMMDD-HHmm.jpg`；logo 取 `assets/logo.png`（即站点 logo）。
  - **赞赏**：插件开关 + 赞赏码图片；没填图自动隐藏按钮；点开弹出赞赏码，长按保存。
  - **分享**：弹卡片显示文章网页地址（点击复制）+ 微信原生转发按钮。
- 顶部悬浮按钮回首页。

### 4. 归档页（packagePost/archive）

- `/api/archives`：封面 + 6 项统计（文章/分类/评论/运行天数等）+ 按月分组文章。
- 开关：「关于页归档」；封面可用 `archiveCover` 覆盖。

### 5. 关于页

- **一言卡片**（开关）：问候语按时间 7 档 + 大号日期 + 配图 + 随机句子 + 署名；点击换一句；下拉刷新。
- **归档入口**（开关）：开启时替换原来的「接口状态」卡。
- **友情链接**（开关）：自动抓取网页端 `/links.html`，**只取链接、不含友链申请要求**；按原分组展示（论坛/博客/导航），缓存 1 小时，下拉关于页可强制刷新。
- 站点地址栏已移除，替换为友情链接。

### 6. 我的页

- 登录（邮箱验证码，WorkBuddy 云服务）+ 收藏 + 浏览记录。
- 顶部显示站点 logo（`assets/logo.png`）。

## 六、友链头像的域名问题（重要）

小程序 `<image>` 只加载白名单域名，外站头像直接引用必然裂图。服务端的处理：

1. 把友链头像下载到 `usr/uploads/miniapp-links/`（md5 命名），返回**自己域名**的地址。
2. 首次请求**先返回文字、头像后台补下**（PHP-FPM 用 `fastcgi_finish_request`），不会拖慢首屏；下载失败或没下完时，前端用「名称首字」色块兜底。
3. 首次部署后前几次刷新可能部分头像显示首字，属正常，稍后再进就全是头像。

> 若目录不可写，头像永远走首字兜底，功能不受影响。缓存 1 小时。

## 七、更新 / 发版流程

**小程序**：开发者工具改代码 → 编译预览 → 上传 → 提交审核 → 发布。

**插件**：上传新版 zip 解压覆盖 `usr/plugins/MiniAppApi/` → 后台禁用 → 启用（保险起见）→ 设置页确认配置还在。

**缓存说明**：轮播 1h、分类封面 1 天、归档封面 1 天、友链 1h，缓存文件在 `sys_get_temp_dir()`。改了网页端内容想立即生效：删除服务器临时目录里的 `miniapp-api-*` 缓存文件，或等缓存到期。

## 八、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 所有接口 404 | 路由没注册：后台禁用→启用插件 |
| 模拟器请求被 CORS 拦 | 开发者工具勾选「不校验合法域名」；真机不受影响 |
| 真机图片裂图 | downloadFile/request 白名单没配 `https://www.xiehongwei.cn` |
| 401/403 | token 不一致：核对插件设置与 `config.js` |
| MySQL 报 Unknown column 'value' | 插件版本过旧，升级到 ≥1.5.2（字段统一为 `str_value`） |
| 一言卡配图空白 | 检查插件里配图/图库目录设置；1.5.5 修复了「目录被当图片地址」的问题，升级插件 |
| 友链头像首字色块 | 头像还没下载完或目录不可写，见第六节 |
| 赞赏按钮不显示 | 「文章页赞赏」关闭，或没填赞赏码图片 |
| 云登录/收藏失败 | 云服务未部署或 `mp-api.app.workbuddy.host` 未加白名单 |
