# 更新日志

服务端插件与微信小程序客户端的版本记录。插件版本号在 `Action.php` 的 `PLUGIN_VERSION` 与 `Plugin.php` 的 `@version` 两处同时维护。

## MiniAppApi 1.5.8

- 新增「关于页友情链接」：抓取网页端 `/links.html`，只解析 `section.links-group` 内的链接，**不解析友链申请要求**；按原分组展示
- 外站头像下载落地到 `usr/uploads/miniapp-links/` 后返回本站地址，规避小程序域名白名单
- 头像改为「缓存优先 + 响应后下载」（PHP-FPM 下 `fastcgi_finish_request`），首次请求不再被头像阻塞
- 小程序「关于」页「站点地址」卡片替换为友情链接；点击条目弹窗显示网址，可复制
- 配置接口新增 `links` 字段，无需新增路由

## MiniAppApi 1.5.7

- 文章页底部改为四宫格：收藏 / 海报 / 赞赏 / 分享（内联 SVG 图标，不依赖图片资源）
- 新增「文章页赞赏」开关与「赞赏码图片」设置；未配图时按钮自动隐藏
- 新增分享弹窗：显示文章网址、一键复制、微信原生转发
- 配置接口新增 `features.reward` 与 `rewardImage`

## MiniAppApi 1.5.6

- 路径类设置全面兼容网址写法：`https://站点/usr/...`、`/wwwroot/...`、`usr/...` 三种均可
- 本站网址自动识别（裸域与 `www.` 视为同一站），转成本地文件读取，不发 HTTP 请求
- 「一言卡片配图」不再把目录误当图片地址：目录 → 随机取图，文件 → 直接使用
- 诗词文件填错时自动回退到图库目录下的 `yiyan.txt`

## MiniAppApi 1.5.5

- 彻底断开官方一言 API：默认不请求任何外部接口，「接口地址」留空即只读本地 txt
- 修复 `hitokotoImage` 填目录导致卡片配图空白的 bug
- 站内资源域名统一规范化为站点设置里的域名（修复裸域 `xiehongwei.cn` 与白名单 `www.` 不一致导致的裂图）

## MiniAppApi 1.5.4

- 一言配图接入站点图库 `usr/themes/HarmonyHues/assets/yiyan/`（webp/jpg/png/gif 随机）
- 新增本地诗词文件 `yiyan.txt`（每行 `句子——作者《出处》`），支持 BOM 与非 UTF-8 转码
- 新增设置项：一言图库目录、本地诗词文件
- 路径解析统一以 `__TYPECHO_ROOT_DIR__` 为基准（不再依赖进程工作目录）

## MiniAppApi 1.5.3

- 新增关于页一言卡片：`/api/hitokoto` 路由 + `featureHitokoto` 开关
- 服务端代理第三方接口，小程序端无需为其配置域名白名单；失败时回退内置句子

## MiniAppApi 1.5.2

- 修复「文章列表为空」：`fields` 表字符串列名统一为 `str_value`，逐个列尝试并兜底异常
- `_fieldValueCols()` 全部失败时返回空映射，不再 500

## MiniAppApi 1.5.1

- 修复启用插件报「代码错误」：`activate()` 每条路由 try/catch，配置读取用 `Options::plugin()` 回填现有值
- 解决启用时表单默认值覆盖配置（token 被清空）的问题

## MiniAppApi 1.5.0

- 三个功能区，均可后台开关：首页轮播、分类页封面、关于页归档
- `/api/archives`：封面 + 6 项统计 + 按月分组文章
- 服务端抓取自身站点 HTML 解析 HarmonyHues 结构（解析前剔除内联 `<style>/<script>`），临时目录缓存

## 客户端 v2.0.0

- 底部四宫格替代原三按钮布局
- 海报改版：3:2 封面、日期白卡、标题与 meta 分栏、页脚 logo + 扫码提示
- 海报二维码指向网页端文章页（不再跳小程序）
- 「我的」页文字徽标替换为站点 logo
- 关于页：一言卡片、归档入口、友情链接
